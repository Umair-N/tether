# Security

Tether can type into terminals and run shell commands as the server user.
Treat access to it like shell access to that user.

Report vulnerabilities privately through [GitHub security advisories](https://github.com/incmak/tether/security/advisories/new), if private reporting is enabled.
The reporting link and private reporting availability are unverified.
Include steps to reproduce and remove secrets from samples.
If private reporting is unavailable, ask for a private contact through a repository issue without vulnerability details.
This repository does not promise a response time.

Supported version: the latest commit on `main`.
See [Signing in and security](README.md#signing-in-and-security) for deployment guidance.
