Tether
GitHub

Answer your coding agents from your phone.

Tether is a chat UI for Claude Code, Codex, and Antigravity in tmux. It runs on your computer, and your agents stay there. There is no Tether account and no cloud.

Let your agent set it up

Paste this into Claude Code or Codex on the machine that will host Tether. About 5 minutes.

Set up Tether on this machine. Read https://incmak.github.io/tether/llms.txt and follow it. You can download the release first. Show me the installer plan and wait for my yes before you install dependencies, change settings, or start services. Never print my access token.

1. Install

Use one way below. They all install the same verified release. Each way shows you a plan before it changes anything.

MachineStatus
LinuxSupported. Needs a systemd user session.
macOSWorks. Tested with Claude Code on one Mac. Codex and Antigravity are not confirmed.
Android (Termux)Installer is ready. Not yet tested on a real phone.
iPhone, iPadCannot host. Use them as the browser.

You need Python 3.11 or newer, tmux, and at least one agent. You do not need root or Node. The macOS system Python is too old, so use brew install python tmux.

Claude Code plugin

  1. In Claude Code, run /plugin marketplace add incmak/tether.
  2. Run /plugin install tether@tether and install the plugin.
  3. Type set up tether and follow the guided setup.

Codex CLI

Use the prompt at the top of this page. It works in Codex with no skill to install.

Terminal

  1. Download and check the release: 
    curl -fL https://raw.githubusercontent.com/incmak/tether/v0.1.7/integrations/claude/tether/skills/setup/bootstrap.py -o tether-bootstrap.py
python3 tether-bootstrap.py
    This writes only under ~/.local/share/tether. It starts no services.
  2. Read the plan. It writes nothing. Fix each failed check. The plan turns on the web terminal if ttyd is installed. To leave it off, add --no-terminal to this command and the next. 
    python3 ~/.local/share/tether/current/install.py --plan --no-build-ui
  3. Apply the plan. This starts the services. 
    python3 ~/.local/share/tether/current/install.py --apply --no-build-ui

The result prints your address and the path of your token file.

Android

  1. Install Termux from F-Droid or GitHub, not Google Play.
  2. Install the packages, then close and reopen Termux: 
    pkg install python tmux nodejs git ttyd termux-services
  3. Run the installer: 
    git clone https://github.com/incmak/tether.git
cd tether
python install.py --plan --no-voice
python install.py --apply --no-voice
  4. Run termux-wake-lock so Android does not stop Termux.

2. Reach it from your phone

Tether listens only on your computer by default. To use it from another device, pick one way. We recommend Tailscale.

Tailscale

  1. Install Tailscale on the computer and the phone. Sign in to the same account on both.
  2. In the Tailscale admin console, DNS page, turn on MagicDNS and HTTPS Certificates.
  3. On the computer, run this. Use your Tether port if it is not 7683. 
    tailscale serve --bg --https=443 http://127.0.0.1:7683
  4. On the phone, open the HTTPS address that the command prints. Add /chat/ to the end.

HTTPS Certificates publish your machine names and tailnet name on a public certificate ledger.

HTTPS reverse proxy

Install with --auth proxy. The proxy must require its own sign-in. See the nginx example.

Same Wi-Fi

Install with --host 0.0.0.0, then open http://your-computer-ip:7683/chat/.

Plain HTTP sends your token and chat without encryption. Use this only on a network you trust. Push notifications and the web app do not work without HTTPS.

3. Start a chat

  1. On the computer, start tmux and an agent: 
    tmux new -s work
claude
  2. Open your Tether address. It ends in /chat/.
  3. Get your sign-in token. Run this on the computer, and paste the result into Tether: 
    cat ~/.config/mobile-tmux/token
  4. Select the session in the sidebar. Send a message.

Treat the token like an SSH key. Anyone with it can run commands as you.

4. Install the web app

Open Tether at your own host's HTTPS address, not this site. The app belongs to that host, and it needs HTTPS.

  • Android, Chrome: tap More, then Install and create shortcut, then Install.
  • iPhone or iPad, Safari: tap Share, then Add to Home Screen.
  • Computer, Chrome: open More, then Cast, save, and share, then Install page as app.

Notifications need the push feature. Install with --push, or run set up tether again to turn it on. Then allow notifications when your browser asks.

5. Add more hosts

Tether on one machine can list your Tether on other machines.

  1. Install Tether on the other machine. Use the steps above.
  2. In Tether, select the host name at the bottom of the sidebar.
  3. Select Add a host.
  4. Type the HTTPS address that tailscale serve status prints on that machine. The name is optional.
  5. Select Add host.

The list shows if each host is online. A host opens at its own address, with its own sign-in, web app, and notifications.

Update or remove

When a new version is out, the sidebar shows a notice. Select Update now. Your chats reconnect after the restart. A failed update goes back to the old version.

The button arrived in v0.1.7. On an older version, update once from the terminal:

tether update --yes

To go back one version:

tether rollback

To remove the services, read the plan, then apply it. This keeps your token and chat data.

python3 ~/.local/share/tether/current/install.py --plan --uninstall
python3 ~/.local/share/tether/current/install.py --apply --uninstall

If something fails

tether: command not found
Add export PATH="$HOME/.local/bin:$PATH" to your shell profile.
The plan has a failed check
Each failed check has a fix. Do the fix, then run the plan again.
My agent is not in the sidebar
Start the agent inside tmux. Tether does not see agents outside tmux.
Tether stops when I log out of Linux
Run loginctl enable-linger $USER. It can need admin permission.
Claude says "Not logged in" on a Mac
Start the Tether service from your Mac desktop session, not from SSH. An SSH session cannot read the login keychain.
The phone cannot open the address
Check that Tailscale is on, on both devices. Check that the address ends in /chat/.
I do not see Update now
The button appears only on release installs. A git checkout updates with git pull, or moves to releases with tether migrate.
I lost control of my token
Remove ~/.config/mobile-tmux/token, then restart the Tether service. Tether makes a new token.

Still stuck? Open an issue with your agent version. Remove private data first.

Security

  • Anyone with access to Tether can control your agents and run commands as you.
  • Do not expose Tether directly to the internet. Use Tailscale, or a proxy with its own sign-in.
  • The installer checks each release against SHA-256 before it installs.
  • This site is static. It has no connection to your hosts, and it does not ask for your token.
  • Agent providers and optional push services keep their own data policies.

Report security problems privately. See SECURITY.md.
